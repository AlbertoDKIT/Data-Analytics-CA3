# Cinematic Virtual Production Data Analysis

This repository contains the Quarto Website for Parts A, B, of the Data Analytics project.

## Main Files

- **Part A – SQL Queries:** `partA_sql.qmd`  
  Contains the SQL queries to explore the database, tables, and results with explanations.

- **Part B – Linear Regression Analysis:** `partB_linear_regression.qmd`  
  Performs linear regression to predict production success rates based on budget and crew size, with plots and interpretation.

## How to Open

1. Open `index.qmd` to navigate the website.  
2. All other pages are linked from the index page.  
3. Ensure the database `data/virtual_production.db` is in the `data/` folder.  
4. Render the website locally in RStudio or Quarto using the “Render” button.
